Repository for Summit Lake CPUE project

Scripts of note:

summit_cpue_exploration.RMD is a markdown exploring 1990 and 1991 CPUE using the Rao-Wu method
data_exploration is a scripting file exploring the data available from past year
samp_size.RMD is a markdown exploring the sample size requirements for the sampling

No analysis scripts have been written. This is all for operational planning

Datasets are scattered. PLOT_TO_USE is the plot to use in op planning for trapping requirements. samp_size_by_precision is a dataset that gives complete precision and accuracy for sample sizes available. 80_power is a trimmed version of this.
